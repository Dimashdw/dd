# Дашборд аналитики платного трафика (Meta Ads) — пустой шаблон

Автономный офлайн-дашборд из 6 вкладок в ОДНОМ файле. Без интернета и библиотек —
чистый HTML/CSS/ванильный JS, графики на SVG. Это **ПУСТОЙ ШАБЛОН** (плейсхолдер
«$1 в день») — реальные цифры подставляются вторым промтом из выгрузки Meta Ads.

## Сборка

```
cd dashboard
python3 build.py
```

Откроет/перезапишет `dist/dashboard.html` — самодостаточный файл. Открывай его
двойным кликом (file://), можно перенести на Рабочий стол или отправить кому угодно —
все 6 вкладок переключаются в любом месте, офлайн.

## Структура

- `src/data.js` — единственный источник данных (массив `daily` + разрезы) и все
  вычисления → `window.DASH`. **Заполнение = замена `daily` и списков-разрезов.**
  В начале файла — карта соответствия колонок выгрузки Meta → поля `daily[]`.
- `src/charts.js` — мини-SVG-графики → `window.CH`.
- `src/theme.css` — токены тем (светлая по умолчанию, тёмная).
- `src/ui.js` — KPI, таблицы, сортировка, вкладки, заставка → `window.UI`.
- `src/tpl/dashboard.html` — шаблон страницы (6 секций-панелей).
- `build.py` — инлайнит всё в один `dist/dashboard.html`.

## Вкладки

Обзор · Воронка · Гео · Когорты · Креативы · Оплаты.

## Как оживить цифры

1. **Реклама** (расход/лиды/клики/гео/креативы) — из выгрузки Meta Ads: заменить
   массив `daily` и списки `geo`/`creatives` в `src/data.js`.
2. **Деньги** (доход/ROAS/когорты) — рекламный кабинет выручку НЕ знает. Внеси
   оплаты в массив `payments` (вкладка «Оплаты») или подключи CRM, затем поставь
   `incomeIsPlaceholder = false`. После этого пересобери (`python3 build.py`).

Пока доход на заглушках — висит честная плашка-предупреждение, а карточка
предельной цены лида нейтральна (не паникует красным).

## Атрибуция продажи → креативу (воронка Qalan)

Воронка: **клик по баннеру-задаче → квиз (родитель оставляет данные, получает
бонус-задачи) → менеджер дозванивается → оплата**. Продажа закрывается оффлайн,
поэтому Meta сама не свяжет оплату с креативом — метку тащим по цепочке:

**1. Meta, объявление → «Параметры URL»:**
```
utm_source=meta&utm_medium=cpc&utm_campaign={{campaign.name}}&utm_content={{ad.name}}&utm_term={{adset.name}}&ad_id={{ad.id}}
```
`{{ad.name}}` Meta подставит сама → `utm_content` = имя креатива. Называй креативы
системно: `drobi_5kl_video_v1`, `geometry_8kl_banner_v2` — это имя станет меткой везде.

**2. Квиз-сайт — поймать метку в скрытые поля формы:**
```js
new URLSearchParams(location.search).forEach(function(v,k){
  localStorage.setItem(k, v);                          // на случай многошагового квиза
  var el = document.querySelector('[name="'+k+'"]'); if (el) el.value = v;
});
```
Тогда вместе с заявкой (имя, телефон, класс ребёнка) уходит `utm_content`.

**3. CRM** — заявка приходит с креативом; менеджер закрывает оплату — креатив уже стоит.

**4. Дашборд** — `payments[].creative` = этот `utm_content`. Оживают лидерборд
креативов, ROAS по креативу и колонка «С какого креатива» в журнале оплат.

> Доп.: чтобы и Meta оптимизировалась на продажи — шли оффлайн-конверсии назад через
> Conversions API / Offline Conversions. Но источник правды для дашборда — поле в CRM.

Реальные рекламные цифры лежат в `src/real-data.js` (его инлайнит `build.py`).
Если файла нет — дашборд работает на заглушках. Чтобы обновить — перезалей
`real-data.js` свежими данными и пересобери.

- Период **05 янв 2026 — 30 июн 2026** (последние ~6 мес, 160 активных дней), валюта **USD**.
- **Реальное:** расход $34 482, клики 202 644, показы 10,2 млн, заявки 6 932 (CPL ≈ $4,97)
  — по дням; гео — по **регионам Казахстана**; креативы — по реальным именам объявлений.
- «Заявки» (leads) = `Website leads` + `Leads (form)` + `Qualified leads`. НЕ считались
  `Messaging conversations`, `Instagram profile visits`, `re_new` (это не заявки на квиз).
- «Прочие объявления» / «Прочее» — агрегат длинного хвоста мелких кампаний (для сходимости).
- **Заглушка (нет в рекламе):** доход, выручка, оплаты, клиенты, ROAS, окупаемость,
  когорты — `incomeIsPlaceholder=true`, плашка висит. Оживут, когда внесёшь оплаты.
- Поправь под себя: реальные тарифы/цены `products` (сейчас $-плейсхолдер), сегменты
  по классу (Meta не разбивает по классу ребёнка — стоит ровная заглушка).

## Что подогнано под Qalan (структура)

- Воронка: Клики → Заявки (квиз) → Дозвон → Оплаты.
- Лестница тарифов по длительности: Бонус-задачи → Месяц → 3 месяца → Год.
- Сегменты по классу ребёнка (1–4 / 5–7 / 8–9 / 10–11).
- Имена креативов = реальные `ad name` (они же ось атрибуции `utm_content`).
